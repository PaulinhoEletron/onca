# Onça Guardiã

**English** · [Português](#português)

An AI agent that reads Brazilian news every week and turns it into a **weekly report of
environmental and climate risks for each region of Brazil**: wildfires, deforestation,
floods, drought and pollution. It uses RAG (retrieval-augmented generation) over the
week's news plus a knowledge base of official guidelines (climate policy, Forest Code,
CONAMA air quality standards, fire management law, the national adaptation plan), and it
remembers earlier reports to show whether risks are rising or falling.

The agent runs on [Hermes Agent](https://github.com/NousResearch/hermes-agent). The
language model can be swapped: a cloud API today, or a local model (Ollama) on university
hardware for data privacy. Text embeddings are always computed locally.

The reports are written in Portuguese. They are generated by AI from news and are **not
official alerts**.

### Status

Work in progress. Done so far: database with Brazil's regions, states and municipalities
(IBGE), and the knowledge base of official guidelines with local embeddings and semantic
search. Next: weekly news collection, region and risk tagging, and report generation.

### How to run

Requirements: [uv](https://docs.astral.sh/uv/) and Docker.

```bash
cp .env.example .env                      # adjust if needed
uv sync
make up                                   # Postgres + pgvector (port 5433 by default)
uv run onca db migrate                    # create tables and load IBGE data
uv run onca geo region "Altamira"         # -> PA / Norte
uv run onca kb ingest                     # download and index the official guidelines
uv run onca kb search "limite de material particulado" -k 5
make check                                # format, lint, type check and tests
make down                                 # stop the database (make clean also deletes the data)
```

`onca kb ingest` downloads the embedding model on first use and runs on CPU; the first
ingest can take several minutes.

## Português

Um agente de IA que lê notícias brasileiras toda semana e as transforma em um **relatório
semanal de riscos ambientais e climáticos para cada região do Brasil**: queimadas,
desmatamento, enchentes, seca e poluição. Ele usa RAG (geração aumentada por recuperação)
sobre as notícias da semana e uma base de conhecimento de diretrizes oficiais (Política
Nacional sobre Mudança do Clima, Código Florestal, padrões de qualidade do ar do CONAMA,
Política Nacional de Manejo Integrado do Fogo, Plano Clima Adaptação), e lembra dos
relatórios anteriores para mostrar se os riscos estão subindo ou caindo.

O agente roda sobre o [Hermes Agent](https://github.com/NousResearch/hermes-agent). O
modelo de linguagem pode ser trocado: uma API na nuvem hoje, ou um modelo local (Ollama)
no hardware da universidade, para privacidade dos dados. Os embeddings dos textos são
sempre calculados localmente.

Os relatórios são escritos em português. Eles são gerados por IA a partir de notícias e
**não são alertas oficiais**.

### Situação

Em desenvolvimento. Pronto até agora: banco de dados com regiões, estados e municípios do
Brasil (IBGE) e a base de conhecimento de diretrizes oficiais com embeddings locais e
busca semântica. Próximos passos: coleta semanal de notícias, classificação por região e
tipo de risco, e geração do relatório.

### Trabalhos relacionados

A Onça Guardiã junta, para o Brasil e em português, técnicas que a pesquisa recente já
validou separadamente: extrair riscos de notícias com LLMs (Ronco et al., 2026; Puime
Pedra et al., 2026; Vela-Tambo et al., 2025), ancorar respostas em fontes oficiais com
RAG (Vaghefi et al., 2023; Lewis et al., 2020), processar textos ambientais em português
(Cação et al., 2021 e 2022; Wang et al., 2024) e organizar o trabalho em agentes de IA
para gestão de riscos (Li et al., 2025). As referências completas estão na seção
[Related work](#related-work), acima.

### Como rodar

Requisitos: [uv](https://docs.astral.sh/uv/) e Docker.

```bash
cp .env.example .env                      # ajuste se necessário
uv sync
make up                                   # Postgres + pgvector (porta 5433 por padrão)
uv run onca db migrate                    # cria as tabelas e carrega os dados do IBGE
uv run onca geo region "Altamira"         # -> PA / Norte
uv run onca kb ingest                     # baixa e indexa as diretrizes oficiais
uv run onca kb search "limite de material particulado" -k 5
make check                                # formatação, lint, tipos e testes
make down                                 # para o banco (make clean também apaga os dados)
```

O `onca kb ingest` baixa o modelo de embeddings no primeiro uso e roda na CPU; a primeira
carga pode levar alguns minutos.
